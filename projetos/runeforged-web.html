RuneForged Web

O portal institucional do universo RuneForged, separado do repositório principal do game para permitir divulgação, conteúdo e integração com as APIs sem bloquear a evolução do jogo.

GitHub ↗

Missão

Dar ao RuneForged uma presença pública própria para apresentar universo, cartas, regras e evolução do projeto.

Separação

O site vive em repositório independente para que apresentação e divulgação possam evoluir sem interferir diretamente no desenvolvimento do game.

Integração

A direção é consumir dados e APIs do ecossistema RuneForged em vez de duplicar manualmente informações do jogo.

Produto

A plataforma também cria uma base para conteúdo institucional, administração e futuras experiências ligadas à comunidade.
